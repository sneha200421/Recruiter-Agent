# AI Recruiter Agent

An AI-powered recruitment assistant designed to streamline the candidate screening and recruitment workflow using intelligent automation.

## 🚀 Overview

AI Recruiter Agent helps recruiters reduce repetitive manual work by assisting with candidate evaluation, resume analysis, job matching, and recruitment-related decision making.

The project demonstrates how AI agents can be integrated into a practical recruitment workflow to improve efficiency and consistency.

## ✨ Features

- 🤖 AI-powered candidate evaluation
- 📄 Resume/CV analysis
- 🎯 Candidate-to-job matching
- 🔍 Candidate information extraction
- 📊 Recruitment workflow assistance
- ⚡ Automated repetitive recruitment tasks
- 💬 Natural-language interaction with the recruitment assistant

## 🛠️ Tech Stack

## ⚙️ Installation
1. Clone the repository
git clone <your-github-repository-url>
cd ai-recruiter-agent

2. Create a virtual environment
   
python -m venv venv

Activate it:
Windows
venv\Scripts\activate

macOS/Linux
source venv/bin/activate

3. Install dependencies
   
pip install -r requirements.txt

5. Configure environment variables
   
Create a .env file in the project root:

OPENAI_API_KEY=your_api_key

Add any other API keys required by the project.

5. Run the application
   
python <main_file>.py

Replace <main_file>.py with the actual entry-point file.
